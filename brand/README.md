# mylocalon brand

The mark is a **location pin** (*local*) with a **power symbol** at its heart (*on*):
your local app, switched on for the internet.

| File | Use it for |
|---|---|
| `mylocalon-mark.svg` · `mark-512.png` | The logo mark on any background (website, docs, slides) |
| `logo-light.png` / `logo-dark.png` | Mark + name, for light / dark backgrounds (READMEs, articles) |
| `mylocalon-app-icon.svg` · `app-icon-512.png` | Square app icon (store listings, social profiles) |
| `avatar-500.png` | GitHub / npm / social avatar |
| `mylocalon-mark-black.svg` / `-white.svg` | One-colour contexts (print, stickers, watermarks) |
| `social-preview.png` | 1280×640 link preview (GitHub repo "Social preview", Open Graph) |

## Colours

| | Hex |
|---|---|
| Indigo (start of gradient) | `#6d5dfc` |
| Sky (end of gradient) | `#22b8f0` |
| Ink (text on light) | `#0f0f1a` |
| Night (dark background) | `#0c0a14` |

The gradient runs top-left → bottom-right: *local* (indigo) warming into *online* (sky).

## Name

Always lowercase: **mylocalon**. In the logo, "on" carries the gradient.

## Please don't

- Recolour the pin outside the gradient or the black/white versions
- Rotate, stretch, outline or add shadows to the mark
- Place the full-colour mark on busy photos — use the white version
